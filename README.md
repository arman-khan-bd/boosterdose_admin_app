# BoosterDose Admin App (Flutter Android)

অ্যান্ড্রয়েড ভিত্তিক পূর্ণাঙ্গ অ্যাডমিন কন্ট্রোল ও ড্যাশবোর্ড মোবাইল অ্যাপ্লিকেশন।

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **অ্যাডমিন লগইন ও অথেন্টিকেশন (Admin Login & Auth)**
   - API Bearer Token ভিত্তিক সুরক্ষিত লগইন
   - ডিফল্ট প্রোডাকশন ডোমেইন: `https://boosterdose.shop/`
   - সার্ভার ডোমেইন কনফিগারেশন টগল (প্রয়োজনে লোকাল বা কাস্টম ডোমেইন দেওয়ার সুবিধা)
   - অটো-লগইন এবং সেশন প্রিজারভেশন (`SharedPreferences`)

2. **ড্যাশবোর্ড ওভারভিউ (Overview & KPIs)**
   - সর্বমোট রাজস্ব, মোট অর্ডার, আজকের অর্ডার ও রাজস্ব, পেন্ডিং ও প্রসেসিং অর্ডার, AOV
   - ১৪ দিনের দৈনিক রাজস্ব ও অর্ডার ট্রেন্ডের ইন্টারঅ্যাক্টিভ চার্ট (`fl_chart`)
   - অর্ডার স্ট্যাটাস বিভাজন (পেন্ডিং, প্রসেসিং, শিপড, ডেলিভার্ড, বাতিল)
   - সর্বাধিক বিক্রিত বইসমূহের ক্যাটালগ
   - সাম্প্রতিক অর্ডার তালিকা ও কুইক ভিউ

3. **অর্ডার ম্যানেজমেন্ট (Orders Manager)**
   - অর্ডার নম্বর, নাম বা ফোন নম্বর দিয়ে ইনস্ট্যান্ট সার্চ
   - স্ট্যাটাস ফিল্টার (All, Pending, Processing, Shipped, Delivered, Cancelled)
   - পেমেন্ট স্ট্যাটাস ফিল্টার
   - ফুল অর্ডার ডিটেইলস (গ্রাহকের ঠিকানা, বই, পরিমাণ, মোট বিল)
   - ১-ক্লিকে গ্রাহককে সরাসরি কল করার সুবিধা
   - ডেলিভারি স্ট্যাটাস ও পেমেন্ট স্ট্যাটাস পরিবর্তন
   - স্টেডফাস্ট (Steadfast) কুরিয়ারে অটোমেটিক ডিসপ্যাচ
   - প্রতারক ফোন নম্বর বা আইপি ব্লক/আনব্লক করার নিরাপত্তা কন্ট্রোল

4. **পরিত্যক্ত কার্ট রিকভারি (Abandoned Carts Manager)**
   - ইনকমপ্লিট অর্ডারের লাইভ লিড ট্র্যাকিং
   - গ্রাহকের সাথে সরাসরি ফোন কল ইন্টিগ্রেশন
   - ১-ক্লিকে পরিত্যক্ত কার্টকে কনফার্মড অর্ডারে কনভার্ট করার সুবিধা
   - রিকভারি স্ট্যাটাস (Pending, Contacted, Recovered, Lost) ও নোটস আপডেট

5. **বই ক্যাটালগ ও স্টক ম্যানেজার (Books Manager)**
   - সকল বইয়ের মূল্য, অফার মূল্য, বিক্রয় পরিসংখ্যান ও স্টক কাউন্টার
   - স্টক শেষ হলে তাৎক্ষণিক সতর্কবার্তা (Out of Stock alert)
   - নতুন বই যুক্ত করা এবং বিদ্যমান বই এডিট/ডিলিট করার সম্পূর্ণ ফর্ম

6. **রিভিউ ও চ্যাট প্রুফ ম্যানেজার (Reviews Manager)**
   - শিক্ষার্থী ও গ্রাহকদের রিভিউ এবং স্ক্রিনশট প্রুফ পর্যবেক্ষণ
   - ১-ট্যাপে রিভিউ অনুমোদন (Approve) বা হোল্ড (Hold)
   - ল্যান্ডিং পেজের জন্য 'ফিচার্ড রিভিউ' নির্বাচন
   - অপ্রয়োজনীয় রিভিউ মুছে ফেলা

7. **কুরিয়ার সার্ভিস ম্যানেজার (Courier Service Manager)**
   - অ্যাক্টিভ কুরিয়ার নির্বাচন (Steadfast, Pathao, RedX, Manual)
   - API Key, Secret Key এবং Access Token কনফিগারেশন
   - কুরিয়ার ভিত্তিক পার্সেল প্রেরণের রিয়েলটাইম পরিসংখ্যান

8. **ল্যান্ডিং সেকশনস ডেটা ম্যানেজার (Sections Data Manager)**
   - ল্যান্ডিং পেজের সেকশনগুলোর সক্রিয়তা সুইচ অন/অফ
   - ড্র্যাগ অ্যান্ড ড্রপ (Drag & Drop) করে সেকশনের ক্রম বা সিরিয়াল পুনর্বিন্যাস

9. **নোটিফিকেশন ও অ্যালার্ট ম্যানেজার (Notification Feed)**
   - নতুন অর্ডার, পরিত্যক্ত কার্ট ও পেন্ডিং রিভিউর জন্য ইউনিফাইড অ্যালার্ট ফিড
   - রিয়েল-টাইম আনরিড কাউন্টার ব্যাজ
   - টেস্ট নোটিফিকেশন পাঠানোর ব্যবস্থা

10. **প্রোফাইল ও নিরাপত্তা (Profile & Security)**
    - অ্যাডমিন নাম ও ইমেইল পরিবর্তন
    - সুরক্ষিত পাসওয়ার্ড আপডেট
    - নিরাপদ লগআউট

## 🛠️ ফোল্ডার স্ট্রাকচার (Clean Architecture)

```
boosterdose_admin_app/
├── android/            # অ্যান্ড্রয়েড বিল্ড ফাইল ও কনফিগারেশন
├── lib/
│   ├── config/         # API URL ও আধুনিক ডার্ক থিম
│   ├── models/         # Data Models (Order, Book, Overview, Review, etc.)
│   ├── providers/      # Provider State Management
│   ├── screens/        # UI Screens (Overview, Orders, Books, Couriers, etc.)
│   ├── services/       # REST API Client & Auth persistence
│   ├── widgets/        # Reusable UI Widgets (MetricCard, StatusBadge, etc.)
│   └── main.dart       # App Entry point
└── pubspec.yaml        # Flutter dependencies
```

## 📱 কীভাবে রান করবেন (How to Run)

```bash
cd boosterdose_admin_app
flutter pub get
flutter run
```
